# Arramooz data attribution

The Arramooz noun-and-verb SQLite database in arramooz-full.sqlite is from the Arabic morphology dictionary maintained at https://github.com/linuxscout/arramooz, upstream revision b055c5dea51b8a9152e7e66a7ca3b6f713fb187d. The upstream README says the dictionary was generated from Ayaspell source data collected manually. arramooz-quran-roots.json is a derived Quran-root subset from the same database.

The upstream project is distributed under GNU General Public License version 2. Its license text is included in ARRAMOOZ-GPL-2.0.txt. This database contains 30,213 noun rows and 10,637 verb rows across 5,573 non-empty roots; stopwords are maintained separately upstream. The Quran-root subset contains 23,306 forms and retains definitions where upstream provides them. Qurabic does not translate or rewrite these definitions.

The Quran-root subset is generated by scripts/lexicon/build-arramooz-family.py. The full SQLite source is queried on demand by /api/arramooz/search; Next.js file tracing includes it in that server route.
